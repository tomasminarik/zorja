# Security

If you find a security problem in Zorja (the iPhone app, the forecast API at `api.zorja.app` or the site at `zorja.app`), please report it privately through GitHub's [private vulnerability reporting](https://github.com/tomasminarik/zorja/security/advisories/new) or by email to hello@tomasminarik.com. Please don't open a public issue or test against the live service in a way that affects other people, such as load or rate-limit testing.

You'll get a reply within a few days.
